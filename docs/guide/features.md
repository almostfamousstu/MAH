# Features

The Micro Automation Hub provides a suite of tools to manage and scale automation within your organization.

## Micro-Automations

**Route:** `/automations`

This is the core workspace where you can discover and manage your automation workflows.
- **Curated Workflows:** Browse a library of approved micro-automations.
- **Trigger Policies:** Define when and how automations run.
- **Run History:** View logs and outcomes of past automation executions.

## Failure Atlas

**Route:** `/failure-atlas`

A knowledge base for incident management and prevention.
- **Incident Ontology:** A shared taxonomy of failure modes.
- **Remediation Playbooks:** Step-by-step guides to resolve known issues.
- **Detection Signals:** Indicators to identify problems before they escalate.

## Training & Culture

**Route:** `/training`

Resources to upskill your team and foster an automation-first culture.
- **Tutorials:** Bite-sized learning modules.
- **Podcasts:** Discussions on automation trends and best practices.
- **Adoption Campaigns:** Materials to promote tool usage.

## MARU Portal

**Route:** `/maru-portal`

The developer portal for onboarding new micro-automations.
- **Developer Onboarding:** Guides and tools for creating new automations.
- **Project Management:** Track the lifecycle of automation projects.

## Insights & Telemetry

**Route:** `/insights`

A unified dashboard for performance and adoption metrics.
- **KPIs:** Key Performance Indicators for automation success.
- **Adoption by Team:** Track which teams are leveraging automation the most.
- **Incident Queue:** Monitor active incidents and their status.

## AI Assistant

**Route:** `/chat`

An integrated AI chat interface.
- **Automation Help:** Ask questions about how to use the platform.
- **Best Practices:** Get advice on designing robust workflows.

## Roadmap

**Route:** `/roadmap`

View the future direction of the platform.
- **Upcoming Features:** See what's shipping next.
- **Feedback Backlog:** Vote on features and submit requests.

## System Development (Explore)

**Route:** `/explore`

A preview area for the "Deep Currents Micro-Automation System Development".
- **Integration Checklist:** Track system integration status.
- **Scene Management:** Manage different stages of the automation lifecycle (Govern, Design & Build, Accelerate).
